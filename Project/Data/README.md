# Data inputs

The analysis scripts expect `Suppl_material.csv` in this directory. The manuscript describes this as the recompilation of 282 soil samples with at least the fields required by the geostatistical scripts (`SampleID`, `X`, `Y`, `Pb`, `Zn`, `Cu`).

`MPM_FullGrid_25m.csv` and `MPM_FullGrid_25m.rds` are generated by `Create_MPM_FullGrid.R` and should normally not be treated as source data.

Before public release, confirm that the source geochemical data can legally be redistributed. If redistribution is restricted, provide a clear Data Availability statement and, where possible, a processed reproducibility table under the applicable permissions.
