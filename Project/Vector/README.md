# Vector inputs

Core occurrence input:
- `occurrences.shp` with its `.dbf`, `.shx`, `.prj` (and `.cpg`, if present) sidecars.

The final map script can also use the geological vector layers (faults, silicified zones, brecciated zones) for overlays. If these layers are redistributed, include the complete shapefile sidecar sets and confirm data-sharing permissions.

CRS: WGS 84 / UTM Zone 35N (EPSG:32635).
