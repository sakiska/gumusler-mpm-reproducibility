# Gumusler MPM - Public R Model Scripts

This directory contains the public, English-language R scripts used to reproduce the analytical workflow reported for the Gumusler Pb-Zn-Cu mineral prospectivity mapping study.

## Scope

The scripts cover geochemical variogram and ordinary-kriging modeling, predictor-grid construction, pseudo-background generation, repeated leave-one-occurrence-out validation, fold-specific preprocessing, RF/XGBoost/SVM training and evaluation, threshold-sensitivity analysis, and final Random Forest ensemble prospectivity mapping.

## Reproducibility principle

Human-facing comments and console/error messages were translated to English for the public release. Computational statements, file names used by the workflow, model settings, thresholds, random seeds, and analytical logic were not intentionally changed.

Run scripts from the repository root so that relative `Project/...` paths resolve correctly.

## Generated model objects

`.rds` model objects produced during geostatistical or machine-learning runs are intentionally not distributed in this `Models` source-code directory. They should be regenerated by the corresponding scripts.
